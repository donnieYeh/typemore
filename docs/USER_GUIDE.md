# Typemore 使用手册

这份文档只面向最终用户，讲“怎么安装、怎么启动、怎么用”。

## 1. 获取 Typemore

最终用户只需要选择以下其中一种形式：

### 方式 1：安装版

获取 `Typemore.msi` 安装包，双击后按安装向导完成安装。

### 方式 2：便携版

获取 `typemore.exe`，直接双击运行即可。

说明：
- 安装版会注册到系统并创建启动入口
- 便携版不会创建开始菜单和桌面快捷方式
- 两者运行效果基本一致

## 2. 启动

### 安装版启动

正式安装后，可以这样启动 Typemore：

1. 从开始菜单打开 `Typemore`
2. 或双击桌面快捷方式

### 便携版启动

直接双击 `typemore.exe`。

### 启动后的表现

启动后会看到：
- 主设置窗口
- 系统托盘图标

关闭主窗口后，程序不会退出，而是隐藏到托盘。

## 3. 首次配置

第一次使用时，请完成以下设置：

1. 打开设置页
2. 填写 `DeepSeek API Key`
3. 点击“自动下载 Whisper 资源”
4. 保存设置

下载完成后，程序会把本地 `whisper.cpp` CLI 和模型写入应用数据目录。

## 4. 开始使用

### 热键方式

1. 在任意第三方输入框中放好光标
2. 单独按一次 `右 Alt`
3. 开始说话
4. 再单独按一次 `右 Alt`
5. 等待结果自动粘贴

### 按钮方式

如果你不想用热键，也可以在主窗口点击：
- `开始录音`
- `停止录音`

## 5. 录音过程中会发生什么

### 悬浮窗状态

桌面底部会出现悬浮状态窗：
- 录音中：波纹持续震荡
- 处理中：波纹停止，保留静态提示
- 完成后：悬浮窗自动关闭

### 文本处理规则

- 很短的本地转写结果会直接输出
- 普通长度文本会做纠错和润色
- 较长内容如果天然有多个点，会自动做轻度结构化整理

## 6. 输出规则

程序会优先尝试把结果直接粘贴到当前活动光标。

如果当前窗口不适合自动投递：
1. 结果会写入剪贴板
2. 程序会弹出通知提示你可以直接粘贴

## 7. 托盘说明

关闭主窗口后，程序仍然在后台运行。

你可以通过托盘：
- 左键打开设置
- 菜单打开设置
- 菜单开始录音
- 菜单停止录音
- 菜单退出程序

## 8. 常见问题

### 1. `右 Alt` 没反应

- 确认按的是 `右 Alt`
- 确认没有和其他键组成组合键
- 确认程序还在托盘中运行

### 2. 结果没有自动粘贴

- 有些窗口会拦截模拟粘贴
- 此时程序会退回剪贴板
- 你可以手动按 `Ctrl + V`

### 3. 主窗口关闭后怎么恢复

- 点击系统托盘图标
- 或在托盘菜单里点“打开设置”

### 4. 安装版和便携版有什么区别

- 安装版会注册到系统并创建启动入口
- 便携版只提供一个可直接运行的 `exe`
- 两者的运行效果基本一致
