# Typemore 使用手册

## 功能概览

Typemore 是一个 Windows 桌面语音转文字工具，核心流程如下：

1. 按 `右 Alt` 开始录音。
2. 再按一次 `右 Alt` 结束录音。
3. 本地 Whisper 模型先做转写。
4. DeepSeek 对转写结果做纠错、润色和轻度结构化整理。
5. 优先把最终文本粘贴到当前活动光标；如果当前无法安全投递，则退回剪贴板并通知。

## 首次使用

1. 启动应用后打开设置页。
2. 填写 `DeepSeek API Key`。
3. 点击“自动下载 Whisper 资源”。
4. 保存设置。

资源下载完成后，Typemore 会把本地 `whisper.cpp` CLI 和 `ggml-small.bin` 模型写入应用数据目录。

## 录音方式

### 热键录音

- 默认只监听 `右 Alt`
- `右 Alt` 单独按下并释放后，不会立刻执行
- 程序会等待一个缓冲时间，默认 `1500ms`
- 缓冲结束后，以缓冲期内最后一次指令为准

这个设计是为了减少误触和快速连按时的抖动。

### 按钮录音

如果你不想用热键，也可以直接在设置主窗口点击：

- `开始录音`
- `停止录音`

## 悬浮窗说明

录音过程中，桌面底部会出现一个悬浮状态窗：

- 录音中：波纹会持续震荡
- 处理中：波纹停止，保持静态提示
- 处理完成：悬浮窗自动关闭

## 输出规则

- 如果当前前台是第三方输入窗口，Typemore 会优先自动粘贴
- 如果当前不适合自动投递，结果会进入剪贴板
- 剪贴板兜底时会弹通知提示“可直接粘贴”

## 文本修复规则

- 本地转写有效字符数 `<= 3` 时，直接输出本地结果，不调用大模型
- 长文本会自动做流畅化修复、口语化清理和轻度结构化整理
- 短文本尽量保持单行

## 托盘行为

Typemore 关闭主窗口时不会退出程序，而是隐藏到托盘。

托盘支持：

- 左键打开设置
- 菜单打开设置
- 菜单开始录音
- 菜单停止录音
- 菜单退出程序

## 常见问题

### 1. 热键没反应

- 确认按的是 `右 Alt`
- 确认没有和其它键同时组成组合键
- 确认程序仍在托盘运行

### 2. 结果没有直接粘贴

- 有些窗口会拦截模拟粘贴
- 这时 Typemore 会退回剪贴板
- 你可以手动 `Ctrl + V`

### 3. 主窗口关掉后怎么找回

- 点击系统托盘图标
- 或在托盘菜单里点“打开设置”
